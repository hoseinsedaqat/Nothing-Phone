- The description and topics are indexed by GitHub search and feed Google's
  repository snippets.
- Keep keywords natural: "Nothing Phone (3)", "Nothing OS 5.0",
  "simulator", "React", "TypeScript", "PWA", "Web Audio".
- The social preview image appears when the repo URL is shared on social
  media, Slack, X, Telegram, LinkedIn and in some Google rich previews.
- The MIT license makes the project safe to star/fork for companies and
  developers who filter by license.
